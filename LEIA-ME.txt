PORTFÓLIO MODERNO — MATHEUS SELIS

Arquivos:
- index.html: estrutura da página
- style.css: aparência e responsividade
- app.ts: código TypeScript do botão de tema
- app.js: JavaScript pronto para o navegador
- tsconfig.json: configuração do TypeScript

COMO ABRIR:
1. Extraia a pasta do ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador.

PARA EDITAR:
- No index.html, altere o texto de apresentação, projetos e contatos.
- Substitua SEU_EMAIL_AQUI e os links de LinkedIn/GitHub pelos seus dados.
- Para compilar o TypeScript depois de alterar app.ts, execute no terminal:
  tsc

O projeto usa HTML, CSS e TypeScript sem frameworks.

PROJETOS E CONTATOS:
- LinkedIn e GitHub já estão ligados na seção Contato; altere os hrefs no index.html se mudar de perfil.
- O e-mail está desativado até substituir SEU_EMAIL_AQUI pelo endereço real.
- Para ligar um cartão de projeto, preencha data-project-url="https://..." no article correspondente no index.html. O botão “Ver projeto” aparece automaticamente.
- Código-fonte deste portfólio: https://github.com/Matheusselis/portfolio-moderno/tree/main
